# مغامرات الأطفال — Kids Adventure Game

لعبة مغامرات تعليمية للأطفال بالعربي المصري، مبنية بمحرك **Godot 4.7.2** (GDScript).

## اللعبة

- اختار البطل: **أرنوب** أو **روبو** أو **ستيكو**
- خريطة عوالم: الغابة، البحر، الصحرا، الفضاء، القلعة (الغابة - المرحلة 1 متاحة في v0.1.0، الباقي قريبًا)
- مرحلة الغابة 1: اجري واقفز، اجمع **5 نجوم**، وصل للكنز، وجاوب سؤالًا تعليميًا سهلًا عشان تكسب
- تحكم: أسهم / WASD / مسافة على الكيبورد، وأزرار لمس كبيرة (يسار / يمين / اقفز) على الموبايل
- حفظ تقدم محلي على الجهاز فقط (`user://save.json`)
- من غير إعلانات، من غير عنف، من غير جمع بيانات، من غير اتصال بالشبكة داخل اللعبة

## التشغيل محليًا

1. نزّل Godot **4.7.2-stable** (النسخة العادية GDScript، مش .NET) من الموقع الرسمي أو GitHub releases.
2. افتح المشروع من `project.godot` وشغّله (F6/F5)، أو من سطر الأوامر:

```bash
godot --headless --import --path .
godot --path .
```

## البناء

- **Web**: إعداد `Web` في `export_presets.cfg`، أو Workflow ‏`build-web.yml` على GitHub Actions.
- **Android**: إعداد `Android` (الحزمة `com.fathy744.kidsadventure`، الإصدار `0.1.0` كود `1`، `min_sdk 24`، `target_sdk 36`، `arm64-v8a`، بناء Gradle بصيغة AAB)، أو Workflow ‏`build-android.yml` لبناء APK تجريبي (Debug) في CI.

توقيع إصدار Google Play (Release AAB) بيتم لاحقًا بمفتاح خاص بصاحب المشروع خارج الريبو. لا توجد أي أسرار أو مفاتيح توقيع داخل هذا الريبو.

## الأصول

كل الرسومات أصلية ومتولدة برمجيًا بسكريبت `tools/generate_assets.py` (Python + Pillow). لإعادة توليدها:

```bash
python3 tools/generate_assets.py
```

## هيكل المشروع

- `scenes/` — القائمة الرئيسية، اختيار البطل، خريطة العوالم، المرحلة 1، البطل، النجمة، الكنز، سؤال الكنز، شاشة الفوز
- `scripts/` — منطق اللعبة والحفظ والتحكم
- `assets/` — رسومات وخلفيات وأيقونة
- `GAME_BLUEPRINT.md` — مخطط اللعبة الكبيرة
- `GOOGLE_PLAY_PLAN.md` — خطة النشر على جوجل بلاي

## الخصوصية

اللعبة لا تجمع ولا ترسل أي بيانات. التقدم بيتحفظ محليًا على جهاز اللاعب فقط.
